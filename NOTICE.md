# Third-party notices

This repository contains deployment configuration and documentation; it does not bundle AFFiNE application source code.

The Docker Compose stack downloads the official AFFiNE image from `ghcr.io/toeverything/affine`. AFFiNE has a split license: repository areas and bundled third-party components can have different terms. Review the upstream [license](https://github.com/toeverything/AFFiNE/blob/canary/LICENSE), [MIT license](https://github.com/toeverything/AFFiNE/blob/canary/LICENSE-MIT), and [backend server license](https://github.com/toeverything/AFFiNE/blob/canary/packages/backend/server/LICENSE) before copying, modifying, or redistributing upstream code or images.

AFFiNE's self-host deployment guide recommends Docker Compose and documents its PostgreSQL, Redis, storage, HTTPS, and backup requirements: <https://docs.affine.pro/self-host-affine/>.
